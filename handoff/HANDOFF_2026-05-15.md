## Build Flag Lesson

An earlier performance-branch output, `redu06`, was much slower than `gw_dev`.
That difference was traced to the build, not the accumulator change.

Build metadata copied from Unity showed:

- `gw_dev` release flags included `-march=native`.
- The old performance-branch build did not include `-march=native`.
- The missing flag applied to `citlali`, `citlali_cli`, `kids`, `gramsavgol`,
  `netcdf-cxx4`, and tests in that build tree.

After reconfiguring and rebuilding the performance branch with native release
flags, the performance branch produced byte-identical checked maps against
`gw_dev` and returned close to the `gw_dev` wall time.

Recommended Unity rebuild pattern for this branch:

```sh
cd ~/work_toltec/citlali_dev/citlali_perf_mapaccum
cmake -S . -B build \
  -DCMAKE_BUILD_TYPE=Release \
  -DCMAKE_C_FLAGS_RELEASE='-O3 -DNDEBUG -march=native' \
  -DCMAKE_CXX_FLAGS_RELEASE='-O3 -DNDEBUG -march=native'
cmake --build build --target citlali_cli -j 20
grep CMAKE_CXX_FLAGS_RELEASE build/CMakeCache.txt
grep 'CXX_FLAGS =' build/CMakeFiles/citlali.dir/flags.make
./build/bin/citlali --version
```
