### User-Facing Correction

To write full jackknife/noise realization FITS files, use:

```yaml
noise_maps:
  enabled: true
  n_noise_maps: 25
  randomize_dets: false
  write_realizations: true
  products:
    enabled: true
    apply_empirical_weights: true
```

The old keys below should not be used:

```yaml
write: true
write_coadd: true
```
