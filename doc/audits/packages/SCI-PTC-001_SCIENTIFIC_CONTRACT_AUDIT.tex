\begin{abstract}
The independently claimed PTC operator is a data-dependent, stateful
correlated-mode transformation with cause-preserving validity, a conditioned
local response, full covariance, explicitly nonprecision detector
coefficients unless stronger conditions are proved, and immutable product
identity.  At application SHA
\code{46ad23888a40f5102cdfd50c06e49a549bdf8a20}, the implemented mean/PCA,
selector, second-pass, and weighting paths realize useful bounded pieces of
that operator, but they do not conform to its validity, response, covariance,
sample-rate, variable-scan-extent, state, or product contracts.  The proposed
verdict is \texttt{amend}: keep current accepted uses at
\texttt{existing\_use\_only}, fail closed on every new response, precision,
uncertainty, coordinate-validity, product-reconstruction, or consumer claim,
and require an exact successor plus independent re-audit before expansion.
\end{abstract}

\section{Claimed and implemented operators}

\subsection{Immutable claimed contract}

For scan \(s\), admitted signal \(x_s\), direct-validity mask \(m_s\),
detector/APT state \(a_s\), fixed policy \(\phi\), and realized
data-dependent state \(\theta_s\), the frozen core claims
\begin{align}
  \theta_s &= T(x_s,m_s,a_s;\phi),\\
  z_s &= F(x_s,m_s,a_s,\theta_s),\\
  w_s &= W(z_s,m_s,a_s,\theta_s),\\
  q_{s+1} &= G(q_s,x_s,m_s,a_s),\\
  P_s &= (z_s,m_s^{\mathrm{out}},w_s,R_s,C_s,q_{s+1},
          \mathcal I_s).
\end{align}
Here \(R_s\) is a bounded realized local response or \unknown{}, \(C_s\) is
the declared covariance object or \unknown{}, and \(\mathcal I_s\) binds
sample/detector/scan/stage, time/rate/phase, units, parentage, processing,
validity causes, and product links.  This is the immutable target represented
by \code{PTC-C1--PTC-C12} and equations
\code{eq:theta-fit--eq:ptc-product} in the core.

For fixed mask, fixed orthonormal detector-mode matrix \(V_k\), and no
data-dependent selection derivative, the conditional special case is
\begin{align}
  \widehat c &= (x\odot g)V_k,\\
  z &= x-\bigl(\widehat cV_k^{\mathsf T}\bigr)\odot g,\\
  C_{z\mid\theta} &= A_\theta C_x A_\theta^{\mathsf T}.
\end{align}
The unconditional Jacobian must additionally include derivatives of fitted
modes, selected \(k\), masks, thresholds, feedback, and state.  A kernel
conditioned on one realized \(\theta\) is not that unconditional response.

\subsection{Compact implemented operator}

Source first subtracts, for every detector \(d\),
\begin{equation}
  \bar x_d^{\,\mathrm{src}} =
  \frac{\sum_t x_{td}g_{td}}{\sum_t g_{td}},\qquad
  x'_{td}=x_{td}-\bar x_d^{\,\mathrm{src}},
  \label{eq:implemented-mean}
\end{equation}
with a NaN mean replaced by zero.  This occurs even when
\code{clean.enabled=false}.  When cleaning is enabled, each configured group
is processed sequentially.  The source forms a flag-masked pairwise
covariance, solves detector eigenmodes, obtains \(k\) from a configured cut,
standard-deviation cut, random circular-shift null, Marchenko--Pastur fit, or
adaptive score, and applies
\begin{equation}
  z=x'-\left[((x'\odot g)V_k)V_k^{\mathsf T}\right]\odot g.
  \label{eq:implemented-pca}
\end{equation}
The kernel follows Equation~\eqref{eq:implemented-mean} and then
Equation~\eqref{eq:implemented-pca} using the signal-derived \(g,V_k,k\).
The optional second pass subsequently derives residual events and mutates
flags, without recomputing the already-cleaned signal/kernel.  Later detector
outlier and weight-threshold stages can flag additional detector columns.

Detector coefficients are selected by type:
\begin{align}
  w_d^{\mathrm{approx}} &=
    \left[\sqrt{f_s}\,f^{\mathrm{cf}}_d\,s^{\mathrm{APT}}_d\right]^{-2},
  \label{eq:implemented-approx}\\
  w_d^{\mathrm{full}} &= \widehat{\Var}(z_d\mid g_d)^{-1},
  \label{eq:implemented-full}\\
  w_d^{\mathrm{hybrid}} &=
    w_d^{\mathrm{approx}}\,
    \operatorname{clip}\!\left[
      \frac{w_d^{\mathrm{full}}/w_d^{\mathrm{approx}}}
           {\operatorname{median}_{d\in A}
             (w_d^{\mathrm{full}}/w_d^{\mathrm{approx}})}
    \right],
  \label{eq:implemented-hybrid}\\
  w_d^{\mathrm{validated}} &= w_d^{\mathrm{approx}}p_d,\qquad
  w_d^{\mathrm{constant}}=1,
  \label{eq:implemented-other}
\end{align}
followed, when configured, by correlation penalties, busy-row suppression,
median caps, and detector-wide threshold flags.  These are per-detector scalar
coefficients.  No path constructs temporal, inter-detector, or
cross-observation precision.

\section{Validity, missing data, and causal influence}

The implementation distinguishes direct sample flags and detector/APT flags,
and mapmaking now refuses to inspect a directly flagged payload.  That is a
useful downstream positive control, but it cannot recover influence already
mixed into an unflagged descendant.

\begin{enumerate}[leftmargin=*]
\item Equation~\eqref{eq:implemented-mean} and the main covariance/projection
use arithmetic multiplication by \(g\).  IEEE \(0\times\mathrm{NaN}\) is NaN.
A focused exact-formula probe with \(x=(1,\mathrm{NaN},3)\) and
\(g=(1,0,1)\) produced a NaN source mean, then the implementation's zero
fallback, instead of the good-only mean 2.  Thus the flagged payload changes
all unflagged output values without an output flag.
\item Null surrogates circularly shift standardized signal columns but retain
the original unshifted validity matrix.  A rejected value may therefore land
at a destination marked good and enter the surrogate covariance and selected
cut.
\item Second-pass robust-statistic fallback uses all finite samples when fewer
than eight eligible values exist.  Baseline smoothing substitutes the median
for flagged/non-finite cells without recording which good outputs are
influenced by those substitutions.
\item Second-pass flags, post-clean bad-detector removal, and weight-threshold
flags occur after the selected signal and kernel have already mixed detector
information.  Only directly rejected cells/columns are marked; affected
unflagged descendants are neither recomputed nor declared ineligible.
\end{enumerate}

These are failures of the approved influence contract, not a request to
broaden mature PCA numerics.  The null-mask mismatch is a concrete selection
contradiction and therefore a narrowly named Tier-A reopen trigger if it
cannot be repaired at the admission/interface boundary.

\section{Response, uncertainty, covariance, and detector coefficients}

\subsection{Response}

Applying the realized signal-derived \(V_k,k,g\) to a kernel provides
\[
  R_{\mathrm{cond}}=A_{\widehat\theta}R_{\mathrm{in}},
\]
conditional on the selected state.  It omits the response of
\(\widehat\theta(x)\), discontinuities in selected \(k\), source-mask and
second-pass selection, learned/fruit state, and uncertainty of all those
terms.  The incoming RTC handoff additionally reports that the supplied
kernel omits donor replacement and alt-az destriping response and lacks
complete causal support.  PTC cannot turn that partial upstream object into a
complete response by projecting it.

The full PTC file may store a \code{kernel} variable; mini output omits it.
The variable has units \code{N/A}, no explicit conditioned/local/global
identity, no parent-response binding, no uncertainty, and no unavailable
state.  Naive/JINC/ML map paths and Beammap use it directly.  Therefore:
\begin{itemize}[leftmargin=*]
\item a bounded realized conditioned kernel may be used only under its exact
state once that state and upstream scope are supplied;
\item a global transfer, absolute beam response, extended-source response, or
response uncertainty is currently \unknown{}; and
\item absence of a complete response must not be encoded as a plausible
partial kernel.
\end{itemize}

\subsection{Uncertainty and covariance}

For fixed state, the conditional covariance is
\(A_{\widehat\theta}C_xA_{\widehat\theta}^{\mathsf T}\).  The implementation
does not produce it.  It also does not produce the additional covariance from
fitted/selected state, calibration, response, random selection, fruit-loop
feedback, or systematics.  Cleaning explicitly creates temporal and
inter-detector correlation; shared calibration and iteration create
cross-product/cross-observation terms.  None is erased by a scalar detector
coefficient.

\subsection{Weight interpretation}

\code{full} is inverse empirical per-detector residual scatter, not a full
precision matrix.  \code{approximate} depends on the unresolved
\code{fcf*sens} factor identity.  \code{hybrid} normalizes a residual-scatter
ratio within array and clips it.  \code{validated} applies learned and
heuristic factors.  \code{constant} is dimensionless.  Correlation and busy
row penalties are additional heuristic coefficient changes.  No type proves
the frozen core's marginal-precision equation plus independence, and no type
provides full retained covariance.

Accordingly, every PTC weight is a nonprecision gridding coefficient at this
SHA.  The NetCDF \code{weights} unit attribute overstates at least the
constant case and does not encode coefficient family, normalization,
lifecycle, or covariance scope.  A map denominator, JINC squared-basis
accumulator, ML row coefficient, or signed noise realization cannot acquire
inverse-variance or significance authority from that attribute.

\section{State, products, metadata, and provenance}

\subsection{Four-state reconstruction}

The typed configuration and one-way adapter provide a useful requested and
effective-policy skeleton.  Observation setup resolves the effective sample
rate and other run context.  The execution-plan/provenance path records the
request, effective configuration, selected observation resolutions, and a
bounded set of fruit-loop outcomes.  It does not reconstruct the exact
operator that produced any one scan.

In particular, the durable record does not bind every configured group to its
realized detector membership, validity/source support, selector and selected
mode count, null shift/random state, pass, coefficient family and factors,
fallback, learned state, conditioned response, covariance status, or product
parent.  Diagnostics expose some of these facts while a process is running,
but a diagnostic variable is not an immutable four-state authority.  Static
APT variables are overwritten when another scan is appended, so they cannot
serve as scan-specific realized state.

\code{d_fsmp=fsmp/factor}.  The PTC TOD and diagnostic writers instead put
\code{telescope.fsmp} in \code{SAMPRATE}.  A successfully written
downsampled product therefore carries a scientifically false time/rate
identity; this is not a mere provenance omission.

For later processed chunks, the current scan-index rule adds the current
length to both endpoints of the preceding interval.  With previous inclusive
bounds \([0,605]\) and current length 607, it writes \([607,1212]\), while
contiguity requires \([606,1212]\).  The error is negative or positive
according to the length change.  The ALIGN handoff's repair commit
\code{5c6309125fef15f7c98e70a62b591c663944b130} is not an ancestor of the
governing application SHA and was neither treated as integrated nor
Unity-validated.

File creation uses an atomic replacement and required writer exceptions
propagate, both positive controls.  Subsequent append operations mutate that
file in place.  A later failure can therefore leave a partial multi-scan
product, and there is no complete-bundle marker, per-component digest, parent
digest, or immutable processing-stage identifier by which a consumer can
prove completeness.

\section{Sequential, parallel, iterative, and simulation paths}

Configured cleaning groups execute in a defined sequence within a scan.  A
fresh cleaner object is copied per call, while scan tasks may concurrently use
one PTC processor.  Cache access and validation-weight state have explicit
mutexes.  These are positive ownership controls, but no governing-SHA test
establishes exact sequential/OpenMP equality of realized group selection,
learned state, random shifts, coefficients, flags, signal, kernel, or products.
Floating aggregation order can in principle perturb selected state near a
threshold; that is a derived test requirement, not an observed current
failure.

Fruit-loop callers order model subtraction, PTC, map feedback, and state
updates, but general PTC provenance does not serialize the complete state
recurrence.  Existing recurrence tests cover controlled map feedback rather
than the full PTC operator.  Simulated observations enter the same PTC calls,
with nearby upstream tone-handling and optional source injection, but neither
state nor tests prove real/simulated interface parity.  No local reduction,
astronomical recovery, or simulation campaign was performed.
