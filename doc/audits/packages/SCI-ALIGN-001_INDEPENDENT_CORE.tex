\section{Clock normalization and the common detector grid}

\subsection{Offset sign, stage, and failure conditions}

The checked conversion of native interface time to the reference-clock
coordinate is
\begin{equation}
 t_{ik}^{(r)}=(E_i-E_r)_{\rm sec}+u_{ik}+\delta_{i\rightarrow r},
 \qquad \delta_{r\rightarrow r}=0.
 \label{eq:clock}
\end{equation}
A positive offset is added: it places a native sample later on the reference
clock than the same uncorrected coordinate.  Acquisition bounds are mapped by
the same transformation.  The offset is never rounded to an integer number
of samples and is applied exactly once, before ordering checks, slot
assignment, gap detection, scan slicing, or interpolation.  Its source,
reference interface, unit, resolution state, and uncertainty are provenance.
An offset with only a magnitude, an unknown sign, an unknown unit, an
incomparable epoch, or an implicit application stage is invalid and fails
closed.  A constant-offset model does not silently absorb clock drift.

Corrected native coordinates must be strictly increasing within each
interface.  Reordering, duplicate timestamps, or a cadence residual outside
the accepted timing model fails rather than silently changing native sample
identity.

\subsection{Detector-led common identity}

The proposed common axis preserves detector sample identity and does not trim
it merely because telescope or HWPR support is missing.  Let the detector
phase \(\phi_D\) be the expected center of slot zero in reference-clock
seconds.  Centers and the set inside mapped detector acquisition bounds are
\begin{align}
 t_n &= \phi_D+n h_D,\notag\\
 n_{\min} &= \left\lceil\frac{B_D^- -\phi_D}{h_D}\right\rceil,
 &n_{\max}&=\left\lceil\frac{B_D^+ -\phi_D}{h_D}\right\rceil-1,
 \qquad \mathcal N=\{n_{\min},\ldots,n_{\max}\}.
 \label{eq:grid}
\end{align}
The local common index is \(j=n-n_{\min}\), zero-based and stable for the
observation.  Its identity is \((o,n)\), not merely the row position \(j\).
An empty \(\mathcal N\) is an invalid observation for this package.

Each original detector row is assigned by the explicit round-half-up rule
\begin{equation}
 n(k)=\left\lfloor
 \frac{t_{Dk}^{(r)}-\phi_D}{h_D}+\frac12
 \right\rfloor,\qquad
 \left|t_{Dk}^{(r)}-t_{n(k)}\right|\leq\epsilon_{\rm slot}<\frac{h_D}{2}.
 \label{eq:slot}
\end{equation}
Exactly one original row may occupy a slot.  A tie at the upper half-slot
maps to the later slot; in normal operation the strict tolerance excludes
such a tie.  Two rows assigned to one slot, or a row outside the detector
acquisition support, fails closed.  The actual corrected native timestamp and
the residual \(t_{Dk}^{(r)}-t_{n(k)}\) remain available; the nominal center
does not erase jitter.

For every common row, the contract carries at least:

\begin{itemize}[nosep]
\item observation \(o\), global detector slot \(n\), local row \(j\), nominal
timestamp \(t_n\), and native timestamp when present;
\item nominal cell support
\(I_n=[t_n-h_D/2,t_n+h_D/2)\) clipped by detector acquisition bounds;
\item native detector row identity or an explicit absence;
\item per-stream/per-variable origin, validity, method, and reason; and
\item nominal duration, acquired detector exposure, and any interpolation
weights and source-row identities.
\end{itemize}

The fundamental origin state is one of \(\state{original}\),
\(\state{synthesized}\), or \(\state{unavailable}\).  Validity is a separate
axis, so an original non-finite datum is \(\state{original}\) and invalid, not
a timing gap.  The method refines origin (exact, linear, circular, held, or
none); a reason explains invalidity or unavailability.

\section{Per-stream alignment and interpolation operators}

\subsection{Exact and linear scalar variables}

For a common time \(t_n\), an exact valid source coordinate yields a one-hot
copy and origin \(\state{original}\).  Otherwise a continuous scalar variable
may be interpolated only between adjacent valid native rows \(a,b\) in one
unbroken valid run, with
\begin{align}
 \lambda_n&=\frac{t_n-t_a}{t_b-t_a},\qquad 0<\lambda_n<1,\notag\\
 y_n&=(1-\lambda_n)x_a+\lambda_n x_b.
 \label{eq:linear}
\end{align}
Both coordinates and values must be finite, units and frame must match, and
the bracket must satisfy the stream's explicit maximum-span policy.  No
extrapolation is permitted.  The endpoints themselves are included exactly;
outside the closed bracket the value is unavailable.  Invalid rows are
barriers: an implementation may not skip across them and describe the result
as an ordinary adjacent interpolation.

\subsection{Circular and angular variables}

Every angular field declares both unit and topology.  A bounded non-wrapping
angle may use Equation~\eqref{eq:linear} after checked unit conversion.  A
circular field with period \(P\) uses the signed shortest difference
\(d_P(a,b)\in(-P/2,P/2]\):
\begin{equation}
 y_n=\operatorname{wrap}_P\!\left(x_a+\lambda_n d_P(x_a,x_b)\right).
 \label{eq:circular}
\end{equation}
An exactly antipodal bracket is ambiguous and unavailable unless a separately
declared unwrap state resolves it.  Coordinate/frame conversion and pointing
correction are excluded: ALIGN preserves the named input frame and only
interpolates a variable whose topology is declared.

\subsection{Step state and non-interpolable variables}

A categorical, Boolean, counter, mode, flag, or hardware state is never
linearly interpolated.  It may be held on an explicitly declared validity
interval \([t_k,t_{k+1})\), with a final interval bounded by acquisition end,
only when its producer contract identifies it as a step process.  A held
value at a non-native common time is \(\state{synthesized}\) with method
\(\state{held}\).  Otherwise exact coincidence is required and the value is
unavailable between samples.  Timestamps and identities are coordinates, not
interpolated measurements.

\subsection{Block operator}

For fixed realized mapping and scalar variables, let \(G_D\) insert or fill
detector slots, \(I_T\) and \(I_H\) align telescope and optional HWPR fields,
and \(S_q\) select scan \(q\).  The numerical output is
\begin{equation}
 \boldsymbol y_q=
 \begin{bmatrix}
 S_qG_D&0&0\\
 0&S_qI_T&0\\
 0&0&S_qI_H
 \end{bmatrix}
 \begin{bmatrix}\boldsymbol x_D\\\boldsymbol x_T\\\boldsymbol x_H\end{bmatrix}
 \equiv A_q\boldsymbol x.
 \label{eq:block}
\end{equation}
Absent HWPR produces an explicitly unavailable channel/state, not fabricated
zeros.  Circular interpolation is the corresponding nonlinear map
\(\boldsymbol y=F(\boldsymbol x,\theta)\); Equation~\eqref{eq:block} is its
local linearization away from wrap ambiguity.  ALIGN is not iterative and has
no fixed-point estimator.

\section{Timing-gap identity and bounded fill}

A detector timing gap is a maximal nonempty run of unoccupied expected slots
inside \(\mathcal N\).  Its stable identity is
\((o,D,n_{\rm start},n_{\rm stop})\), where
\([n_{\rm start},n_{\rm stop})\) is half-open.  Consecutive absent slots form
one gap.  Native rows whose values are non-finite do not become timing gaps;
they retain original row identity and invalidity.

For an internal gap of \(g\) missing slots between adjacent original slots
with values \(x_0,x_{g+1}\), detector column \(p\) may be filled only when
both endpoints are finite and valid and both the count and elapsed-duration
limits are accepted.  The unique proposed fill is
\begin{equation}
 \widehat x_{j,p}=\left(1-\frac{j}{g+1}\right)x_{0,p}
 +\frac{j}{g+1}x_{g+1,p},\qquad j=1,\ldots,g.
 \label{eq:gap}
\end{equation}
Each filled cell is \(\state{synthesized}\) with both endpoint identities and
weights.  If either endpoint for a detector is invalid, that detector's gap
cell is unavailable even if other detector columns can be filled.

Leading or trailing gaps are never extrapolated.  A gap exceeding either
limit is not partially filled; every missing slot in the run remains
unavailable.  A gap touching an observation boundary is clipped only for
identity/reporting, not converted into an internal gap.  Every run records
extent in slots and seconds, classification (internal, leading, trailing,
long, or invalid-endpoint), action, and realized counts.  Whether a long gap
must fail the whole observation is a scientific policy decision; regardless,
unavailable samples must fail closed for any consumer requiring a value.

Telescope/HWPR source gaps are defined per variable as maximal invalid or
missing native brackets.  Equation~\eqref{eq:linear} may not bridge a source
gap unless the same explicit bounded-gap policy classifies and records the
result as synthesized.

\section{Scan construction and slicing}

The scan contract is a partition of the common detector slots, not a second
time coordinate.  The default policy creates one scan over all of
\(\mathcal N\).  A requested fixed duration \(L>0\) resolves to
\begin{equation}
 M=\left\lfloor\frac{L}{h_D}+\frac12\right\rfloor\geq1,\qquad
 J_q=[qM,\min\{(q+1)M,N\}),\quad q=0,\ldots,\left\lceil\frac NM\right\rceil-1.
 \label{eq:scans}
\end{equation}
The same round-half-up rule is used and the effective duration \(Mh_D\) is
recorded.  Scan index \(q\) is zero-based and stable in the full observation.
A processing subset preserves original \(q\); it does not renumber scans.
Any persisted one-based presentation is a separately named representation,
not a change to internal identity.

Every interval is half-open.  A boundary slot belongs only to the later
scan.  Windows do not overlap, every selected common slot occurs exactly
once, and the final partial scan is retained.  A short scan is marked short
with its realized sample count and duration; it is not padded or silently
dropped.  If a future explicit-window authority produces an empty window, its
stable scan identity is retained with status \(\state{empty}\), but no numerical
processor is invoked.  Overlapping windows are rejected unless a successor
contract explicitly defines multiple membership and downstream exposure.
Truncation at observation bounds is explicit and preserves the final sample
whose center lies below the half-open stop.

The selection matrix in Equation~\eqref{eq:block} is
\begin{equation}
 (S_q)_{a j}=\mathbf 1\{j=qM+a\},\qquad j\in J_q.
 \label{eq:selection}
\end{equation}
Slicing changes support and window response but not sample units or origin.

\section{Response and normalization}

For fixed \(A_q\) and a temporal template \(\boldsymbol p\), the conditional
response is
\begin{equation}
 R_q(\boldsymbol p)=\frac{\partial\E[\boldsymbol y_q\mid A_q]}
 {\partial\alpha}=A_q\boldsymbol p,
 \quad\text{when }\E[\boldsymbol x]=\alpha\boldsymbol p+\boldsymbol\mu_0.
 \label{eq:response}
\end{equation}
Exact copy and linear interpolation preserve a constant (DC) signal.
Equation~\eqref{eq:gap} also reproduces an affine function of time exactly
when timestamps are on the claimed grid.  It does not preserve arbitrary
high-frequency structure.

For uniform samples and a fractional target \((k+\alpha)h\), \(0\leq\alpha\leq1\),
linear interpolation has response relative to an ideal fractional delay
\begin{equation}
 H_{\alpha}(\omega)=e^{-i\omega\alpha h}
 \left[(1-\alpha)+\alpha e^{i\omega h}\right].
 \label{eq:fractional-response}
\end{equation}
Thus \(H_{\alpha}(0)=1\), while amplitude and phase depend on frequency and
fractional position.  Gap filling is nonstationary: each filled row has the
two endpoint weights in Equation~\eqref{eq:gap}, so it needs a row-specific
response rather than one global transfer function.  Scan slicing multiplies
the common stream by a rectangular support window; it introduces no amplitude
renormalization but affects any later temporal-frequency estimator.

ALIGN performs no unit or photometric calibration.  Constant-signal
preservation is its photometric/DC statement; attenuation of varying signals
is the temporal interpolation response and must not be advertised as unity.
Spatial, WCS, beam/template, extended-source, and iteration-to-iteration
responses are not ALIGN estimators and are addressed explicitly in
Section~\ref{sec:na}.

\section{Formal covariance and uncertainty}

For a fixed realized affine mapping and full joint native covariance \(C_x\),
including cross-detector, cross-time, and cross-stream terms when known,
\begin{align}
 \E[\boldsymbol y_q\mid A_q]&=A_q\E[\boldsymbol x\mid A_q],\notag\\
 C_{y_q\mid A_q}&=A_qC_{x\mid A_q}A_q^{\mathsf T}.
 \label{eq:covariance}
\end{align}
For Equation~\eqref{eq:linear}, one scalar variance is
\begin{equation}
 \Var(y_n)=(1-\lambda_n)^2\Var(x_a)+\lambda_n^2\Var(x_b)
 +2\lambda_n(1-\lambda_n)\Cov(x_a,x_b).
 \label{eq:linear-variance}
\end{equation}
Adjacent outputs that share endpoints are correlated.  Interpolated detector
columns also retain native cross-detector covariance.  Neither smaller
diagonal variance nor smooth appearance means new independent information.
If input covariance is unavailable, ALIGN must say so; it may not invent an
independent white-noise model or an inverse variance.

Uncertain offsets, epochs, clock drift, and jitter contribute timing
uncertainty.  For differentiable signals and timing parameter vector
\(\boldsymbol\eta\), the first-order term is
\begin{equation}
 C_{\rm timing}=J_{\eta}C_{\eta}J_{\eta}^{\mathsf T},
 \qquad (J_{\eta})_{ab}=\frac{\partial y_a}{\partial\eta_b}.
 \label{eq:timing-covariance}
\end{equation}
This is systematic/response uncertainty, not detector noise.  The full
reported target is
\begin{equation}
 C_y=C_{y\mid A}+C_{\rm timing}+C_{\rm interp.model}
 +C_{\rm policy/selection},
 \label{eq:full-uncertainty}
\end{equation}
with absent terms labeled unavailable rather than zero.  The final term is
needed for unconditional claims when mapping or selection is data-derived;
conditional products must say that it was conditioned upon.

For twice differentiable scalar truth \(f\) on a bracket of width
\(\Delta=t_b-t_a\), linear interpolation has the deterministic bound
\begin{equation}
 |f(t)-I f(t)|\leq\frac{\Delta^2}{8}
 \sup_{s\in[t_a,t_b]}|f''(s)|.
 \label{eq:interp-bound}
\end{equation}
This bounds interpolation model error only when the curvature bound is
scientifically justified.  Otherwise \(C_{\rm interp.model}\) is unknown.
Circular interpolation uses the local unwrapped derivative away from the
antipodal ambiguity.

ALIGN does not estimate empirical variance, confidence, statistical weight,
or detector calibration uncertainty.  It supplies mapping and state needed
for owners to propagate them.  Variance, inverse variance, sample support,
validity, hit count, exposure/coverage, confidence, and response remain
distinct quantities.

\section{Duration, exposure, and support}

Each common slot has nominal cell duration
\(\Delta_n=|I_n|\).  Its acquired detector exposure is
\begin{equation}
 e_{np}=\begin{cases}
 |I_n\cap I^{\rm native}_{kp}|,&\text{one valid original detector sample }k,\\
 0,&\text{synthesized or unavailable detector value.}
 \end{cases}
 \label{eq:exposure}
\end{equation}
If detector exposure is not detector-specific, the \(p\) index is omitted.
A synthesized value occupies a target slot and may support continuity, but it
does not add acquired integration time, a hit, or independent statistical
weight.  Telescope/HWPR interpolation likewise creates no detector exposure.
Downstream coverage may sum only explicitly eligible acquired exposure; it
must not sum nominal cell widths for synthesized samples by convenience.

Scan duration, elapsed span, acquired exposure, valid original exposure, and
synthesized slot count are separately reported.  Overlap is prohibited by the
base scan contract precisely so exposure is not double counted.

\section{Validity, eligibility facts, and failure policy}

For each output cell the contract carries the product state
\begin{equation}
 Q=(\text{origin},\text{validity},\text{method},\text{reason},
 \text{source IDs},\text{weights}).
 \label{eq:quality}
\end{equation}
An available numeric value requires finite inputs and a permitted operator.
NaN, zero, or a negative number is never the sole encoding of missing,
disabled, unavailable, or invalid.  Original versus synthesized is always
queryable independently of finiteness.

ALIGN owns only alignment validity: whether a value is present, mathematically
defined under the selected operator, and traceable to native samples.  It does
not absorb CAL/AST/RTC/VAL science-selection policy.  For a consumer requiring
detector value and aligned telescope variable set \(\mathcal V\), the strict
alignment fact is
\begin{equation}
 a_{np}^{\rm strict}=
 \mathbf1\{D_{np}\text{ is original and valid}\}
 \prod_{v\in\mathcal V}\mathbf1\{T_{vn}\text{ is available and valid}\}.
 \label{eq:strict-eligibility}
\end{equation}
This is a supplied fact, not authorization for a downstream estimator.
Synthesized detector values are excluded from strict eligibility by default;
any scientific use requires an explicit consumer contract that accounts for
response, covariance, and zero acquired exposure.  A separate
\(\state{continuity\_available}\) fact may include valid synthesized values for
a bounded algorithmic purpose, but it may not be relabeled original or
science-eligible.

The following fail before scientific conditioning: invalid/ambiguous offset
unit, sign, reference, or stage; incomparable epochs; nonpositive cadence;
nonmonotonic/duplicate time identity; ambiguous detector-slot assignment;
multiple original rows in a slot; undeclared interpolation topology; invalid
scan overlap; or inability to publish required realized provenance.  Missing
optional HWPR is explicit and nonfatal while polarimetric interpretation stays
unavailable.  Missing required telescope variables or all-unavailable common
support fail any consumer that requires them.  Long-gap whole-observation
failure versus marked unavailability remains an owner policy, but invalid
success is never allowed.

\section{Analytic limits and pre-registered falsification tests}

All categorical identities, counts, memberships, and masks compare exactly.
For deterministic double-precision fixtures, finite scalar values compare to
the analytic result at relative tolerance \(10^{-12}\) and absolute tolerance
\(64\epsilon_{\rm mach}\max(1,h_D)\) in the declared unit; circular results
compare by wrapped distance at \(10^{-12}\) rad.  Covariance compares at
relative tolerance \(10^{-12}\) with exact sparsity/source-weight identity.
Any implementation using lower precision must declare and justify a
successor tolerance before results are examined.
