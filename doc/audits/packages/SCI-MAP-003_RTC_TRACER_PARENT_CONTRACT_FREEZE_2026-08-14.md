## Approved exact discrete tracer contract

For one exact terminal response cell, detector component `d`, and retained
map pixel `(r,c)`, define a dimensionless circular Gaussian component

```text
phi_d(r,c) = exp(-rho_d(r,c)^2 / (2 sigma_d^2))
sigma_d = FWHM_d / (2 sqrt(2 ln 2))
```

when `rho_d(r,c) <= 3 sigma_d`, and define `phi_d(r,c) = 0` when
`rho_d(r,c) > 3 sigma_d`. The exact reference plane is

```text
g(r,c) = (1.0 mJy/beam) * sum_d(w_d(r,c) * phi_d(r,c)) / C(r,c)
```

where the detector population, realized eligibility, weights `w_d`, and
formal support denominator `C` are exactly those of the terminal `k = K/C`
parent. No later peak, integral, DC, or global-sum normalization is allowed.

### Fourteen required field groups

Every realization must persist all fourteen groups below. Missing, ambiguous,
non-finite, incompatible, or unverifiable required content makes `g`
unavailable.

| Group | Required exact content | Approved rule |
| --- | --- | --- |
| G01 source identity | observation, reduction, product cell, band/array, mode, map slot, Stokes identity, terminal `k` parent, source APT and source-kernel artifacts | Bind one exact terminal response experiment; no nominal or cross-product substitution. |
| G02 construction route | construction algorithm and route identifier | Render directly on the exact retained terminal-parent grid. No larger intermediate grid, reprojection, resampling, interpolation, or independent recentering. |
| G03 units and amplitude | component amplitude, map unit, beam convention | Every component has peak amplitude exactly `1.0 mJy/beam`; this is a reference injection, not observed source flux. |
| G04 WCS and pixelization | full-precision WCS, axis/frame/epoch, handedness, rotation, scale, FITS/in-memory index convention, pixelization rule | Evaluate each Gaussian at the WCS-defined pixel center; persist `pixel_center_sampled`. No supersampling, footprint integration, or pixel-area correction. |
| G05 center | full-precision `CRVAL`, frame/epoch, fractional `CRPIX` | Use one common terminal-parent WCS reference center for every component. Do not fit, snap, or use detector-specific previous-pass centers. |
| G06 grid shape | exact `N_y x N_x`, row/column ordering, map slot and Stokes cell | Inherit the terminal parent exactly; `g` and `k` must have identical retained shape and indexing. |
| G07 masks, support, and validity | detector exclusions with causes, WCS validity, formal `C` validity, full rectangular support, construction validity | Apply no additional spatial mask. Intentional truncation zeros are valid. Any invalid pixel makes the complete realization unavailable; no zero-fill, interpolation, inpainting, or silent shrink. Preserve `g` validity separately from `k` observational validity. |
| G08 Gaussian family and parameters | family, realized per-detector FWHM, units, source class, source artifact/field | Use circular symmetric Gaussians and the exact realized positive finite FWHM used by the parent reduction. | G09 truncation | sigma limit, comparator, metric, frame, units | Truncate each component independently at inclusive `rho <= 3 sigma` in the parent tangent plane; outside values are intentional zeros. |
| G10 APT rows, detector mixture, and weights | immutable APT identity/digest, APT row IDs, detector IDs, realized eligibility, exact weights and selection digest | Use exactly the population and contribution weights of the terminal parent. ## RTC complete-response-or-unavailable manifest

### Sole admissible terminal stage

The sole admissible RTC response parent is
`rtc_conditioned_inner_terminal`, the immutable inner terminal RTC state
immediately before PTC consumption. It is after every enabled RTC
signal-changing stage, inner crop, phase-zero downsampling, and relevant
support/eligibility resolution. Outer RTC, pre-crop, diagnostic, mini-TOD, or
generic `RTC` products are not substitutes.

### Required top-level experiment and object identity

The ordered stage records are necessary but not sufficient. Every manifest
also requires the following top-level fields so that it identifies one exact
conditioned experiment and one immutable completed-or-unavailable response
object:

- exact input observation and reduction identities and digests;
- exact detector and cohort identities and digests;
- exact scan identity and digest;
- exact sample origin and native-time origin identities and digests;
- exact grid and WCS identities and digests;
- exact support and validity identities and digests;
- exact input-parent identities and digests;
- distinct requested, effective, observation-resolved, and realized state;
- exact output-stage identity, which must name
  `rtc_conditioned_inner_terminal` for the admissible RTC parent;
- top-level response state, exactly `complete` or `unavailable`; an
  `unavailable` response requires a nonempty list from the controlled reason
  vocabulary below;
- normalization state at the RTC-terminal/PTC boundary and separately before
  JINC consumption; and
- final-manifest SHA-256 over exact persisted bytes, exact byte count,
  bundle/member identities, and manifest-object completion state, exactly
  `complete` or `failed`.

Manifest-object state `complete` means that the immutable manifest truthfully
records either a complete response or an unavailable response with controlled
reasons. Manifest-object state `failed` means that no admissible immutable
response object was completed and the object cannot be used as a parent. These
top-level fields complete the accepted D003 lifecycle identity; they do not
add a scientific decision or claim that an implementation already persists
them.
