    finalize -->|"next fruit-loop iteration"| iter

The fruit-loop back edge intentionally returns to the reduction iteration loop, not to TolTECA config generation or the initial geometry pass. In the current control flow, each fruit-loop iteration repeats the per-observation reduction loop, including observation input prep, fruit-loop map loading, TOD processing, observation output/coadd accumulation, and iteration finalization. The initial map geometry pass is outside that loop and is reused.
