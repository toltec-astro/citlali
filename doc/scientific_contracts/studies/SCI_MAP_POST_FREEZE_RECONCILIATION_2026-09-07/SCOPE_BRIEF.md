application test code. Each case traces to shared scientific authority:

| Case | Required distinction |
| --- | --- |
| Zero cut and empty population | Zero cut cannot restore zero, negative, nonfinite or absent normalization; empty input creates no supported row. |

| Registered family without actual handoff | Registration cannot replace selected family, complete parent publication, exact payload association or the required independent decisions. |
