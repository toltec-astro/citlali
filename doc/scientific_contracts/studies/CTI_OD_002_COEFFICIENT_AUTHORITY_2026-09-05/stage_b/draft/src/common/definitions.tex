\section{Scientific meaning of the uniform family}

For every occurrence in its exact declared support, the PTC-owned coefficient
is one. It is a transparent reference family: relative differences in a
downstream contribution cannot originate from this coefficient. Other
producer and consumer facts can still make contributions unequal or unusable.
The constant is fixed at exact one because any positive common scale would be
removed by mean-one normalization and would add a parameter with no surviving
meaning.

Uniformity concerns only the positive PTC analysis/gridding coefficient. It
does not assert equal signal quality, exposure, response, uncertainty,
precision, significance, detector independence, or optimality. It does not
restore an invalid sample, create support, or override a consumer gate. An
occurrence authoritatively outside support has no coefficient under this
family; absence is not numerical zero.

\subsection{Handoff decisions and ownership}

The proposed named-use profile asks whether one attempted handoff has the
right selected family, exact parents and support, a faithful payload, and
permission for one named consumer. The request to evaluate this profile is
independent of the selected-family fact. Thus an explicit profile request with
a known different selected family reaches UQ-01 and is ineligible; no explicit
profile request creates no evaluation.

Payload fidelity is a producer-owned property shared by every handoff that
uses the same immutable payload. It is composed from independently assessable
scalar-value, unit, integrity, and support-membership facts. A decisive false
in any one fact is not hidden by an unrelated unknown. Contradictory claims
about the same fact remain a conflict. A faithful payload is not made corrupt
by consumer policy: a complete authoritative denial makes only that named use
ineligible, while missing or conflicting permission evidence leaves that use
decision unavailable absent another decisive false.

The scope follows the object that is defective. A malformed reference in one
handoff request affects only that attempted request. A defect in a shared
authoritative support, scalar publication, family generation, or source
binding affects every request that references that object. A named-consumer
permission result affects that consumer and does not determine the other
consumer.

Request, applicability, eligibility, and realization answer different
questions. A requested and applicable profile can finish with an ineligible
or decision-unavailable result; that completed negative or unresolved result
is still a successfully realized scientific record. Failure to finalize the
record instead leaves no completed evaluation to reinterpret. No exception,
override, or advisory fact can bypass identity, payload fidelity, or the
named-consumer permission needed for that use.

\subsection{Consumer boundaries}

For MAP, the proposed family supplies only the existing PTC coefficient facet;
MAP retains its own admission, placement, exposure, coordinate, and numerical
classification rules. For JINC, the PTC factor becomes one while JINC retains
the signed spatial factor, normalization, conditioning, and support. MAP and
JINC permissions are independent and remain proposed rather than granted.

A stored one never supplies missing selection, authority, provenance, or
permission. The explicit PTC-disabled route remains RTC-terminal and creates
no PTC coefficient or MAP route. The ordinary-route positive-rank limits are
stated from their admitted frozen source; this contract infers no identity,
zero-rank, or other route family. NOI still requires the exact lossless
rational parent for the selected MAP and coefficient generations and gains no
new route or design rule.

\section{Formal consumer-boundary proposal}

The proposed MAP boundary successor is \MapBoundaryDraft. It changes only the
coefficient-slot binding. MAP may retrieve exact \(\gamma_i=\omega_i=1\) only
after the family record explicitly grants SCI-MAP permission and the named
profile evaluation is requested, applicable, eligible, and realized. MAP
retains every existing admission, placement, exposure, response, coordinate,
support, arithmetic, failure, and finite-strictly-positive classification
rule.

The proposed JINC boundary successor is \JincBoundaryDraft. It changes only
the PTC coefficient binding and requires separately explicit SCI-JINC
permission. JINC retains ownership of its spatial factor \(\kappa_{ip}\), its
sign, normalization, conditioning, support, gates, and bundle semantics. No
response, covariance, uncertainty, or new bundle role is created.

Neither consumer may infer the family from a value, unit, label, another
consumer, or missing selection. There is no unity, alternate-family,
neighboring-product, direct-CAL, no-op-PTC, reconstruction, or
generation-repair fallback. The NOI design law and exact rational-parent
requirement remain unchanged.
