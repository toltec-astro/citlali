\section{Evidence required after owner adoption}

Eventual conformance evidence must bind the exact approved source and Registry
records. Algebraic tests must cover nonempty populations across detector,
time, group, segment, array, and network labels; singleton support; exact
mean-one results; and exact scalar broadcast membership. Negative tests must
cover empty, duplicate, ambiguous, or changed support; parameter overrides;
wrong unit/operator/family; missing or non-one payload; unreadable or
unrepresentable value; wrong product or generation; absent consumer
permission; and cross-generation borrowing. Replay evidence must show exact
numerical reproducibility while retaining distinct immutable generations.

Profile evidence must exercise T/F/U/C composition, all four decision axes,
nonexceptionability, structural versus non-gating conflict, payload ordering,
cause preservation, and every failure scope. Boundary evidence must show MAP
and JINC performing independent numerical classification and admission,
permissions not crossing, and no fallback route. NOI evidence, if that
independently governed route becomes evaluable, must bind the exact MAP value
and canonical lossless rational parent without changing MAP arithmetic.

Scientific validation is a separate future activity. It requires
owner-approved observational or simulation populations, comparison questions,
metrics, uncertainty treatment, and acceptance criteria. None is invented
here. Such evidence could establish comparative performance or suitability;
algebraic tests cannot. Production readiness adds operational completeness and
failure-handling evidence only after scientific and implementation conformance
are established.
