# POINT operational-gate trial

The owner approved execution of the eight-state design and a 1-arcsec
per-observation pointing-error criterion on 2026-09-12.
[PROTOCOL.md](PROTOCOL.md) binds one central-starlet candidate with a larger
predeclared solve budget, the matched pixelwise control, and all evaluation,
failure, timing and resource rules. [CASES.json](CASES.json) supplies the exact
numeric case definitions. `FREEZE.json` binds sources and inputs before execution.

The historical results, accepted scientific sources and protected archives
remain preserved. This is a local development trial, not production or
qualification; no 129081 comparison is included.
