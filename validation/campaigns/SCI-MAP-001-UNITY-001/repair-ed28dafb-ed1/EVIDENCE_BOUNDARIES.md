# Evidence boundaries

## Package-preparation evidence

The local verifier, synthetic fixtures, source inspection, metadata counts,
resource arithmetic, and independent read-only review establish that this
package is internally runnable and fail-closed. They are not Unity execution
evidence and do not change MAP conformance or finding state.

The exact candidate and tree are fixed in `campaign.json`. The predecessor
package tree and checksum-list digest, the four ED1 stop-return artifacts, the
seven-case object, and all coordination hashes are tested. Only this sibling
package may change in the ED2 implementation commit.

## Future input authority

The human must create two fresh TolProj projects from the exact JSON specs.
Each required raw basename must resolve to exactly one canonical regular file
beneath the explicit owner-verified raw root. The staging manifest records
observation, basename, absolute resolved target, filesystem identity, size,
and SHA-256 before creating one file symlink at a fresh destination. Missing,
ambiguous, non-regular, unresolved, duplicate-basename, pre-existing, or
identity-mismatched state stops. Directory links, alternate raw transfer, and
`tolproj copy-raw` after link staging are prohibited.

Only `apt_152389_matched.ecsv`, `apt_152390_matched.ecsv`,
`apt_152392_matched.ecsv`, and exactly one `ppt_*.ecsv` for each of 152389,
152391, and 152393 may be copied and digest-bound. Old reductions—including
the local `citlali-validation/v1` suite—are read-only discovery references,
not evidence inputs or rsync payloads. No Unity counterpart is assumed.

## Capture and rate authority

CAP-POINT and CAP-SCIENCE are evidence-input reductions, not acceptance cases.
Their fully realized merged configurations, numbered-source order, and
included-fragment inventory must match P-SEQ and S-E-SEQ respectively except
for these exact leaves:

- `timestream.processed_time_chunk.output.enabled = true`
- `timestream.processed_time_chunk.output.mode = full`
- `timestream.processed_time_chunk.output.indices = all`

The ordinary candidate binary digest and build/version records must be equal
for both captures and all seven cases. Full PTC is retained primitive
authority. Its `SAMPRATE` remains native `telescope.fsmp`; the independent
effective-rate record binds finite-positive `telescope.d_fsmp` in decimal and
hex form, binds a positive integral downsample factor, proves bit-exact
`telescope.d_fsmp == telescope.fsmp / downsample_factor`, and supplies every
interval/exposure calculation. A mismatch or
missing primitive is a stop, not an inference opportunity.

The compact authority carries separate digests for the realized raw
timestream provenance (native/effective rates and cardinality) and realized
mapmaking provenance (projection, bundle, shape, WCS, target, and pixel size).
Those roles are never interchangeable.

## Compact and final-product authority

The nine compact groups are independent inputs to the analyzer. Complete
order/population digests bind every streamed primitive without retaining a
full-term vector in the compact output. The sufficient statistics, fixed
realization signs, deterministic traces, and typed absence facts are the
reconstruction authority. Final candidate FITS products are comparison
subjects only and cannot be their own authority.

The analyzer retains one token-gated, small full-term fixture reader solely as
a local parity oracle for its synthetic self-check. No command exposes that
reader, and result collection recursively rejects every retired ledger/input
key. It is not an accepted campaign authority or an alternate evidence route.

Focused expansion is allowed only for identifiers already named in a bounded
discrepancy request. It rescans the same retained, digest-bound capture in two
passes, emits only the requested bounded records, and cannot expand the
scientific gate or production scope.

Every material output stage has a digest-bound local planning estimate and
fresh pre/post Unity-root records. The estimate is operational context only;
it is not a source-derived full/all-PTC serialization bound or a guarantee.
Inventory covers directory allocation as well as regular files and symlink
link-text, without traversing canonical raw targets. Resource records,
analysis, manifest, evidence, and return artifacts are rooted beneath the
governed compact tree. The owner stops before the next stage if measured use
approaches/exceeds the cap or capacity is inadequate; that condition cannot
authorize deletion, a larger ceiling, or an alternate transfer path.

## Claims explicitly not made

This package does not provide Unity execution, external evidence, fresh
re-audit, integration, closure of F009/F010/F012/F013 or any CAL/AST/PTC/VAL
dependency, production admission, or cleanup eligibility. An exit-zero local
test means only that package logic passed against local fixtures.
